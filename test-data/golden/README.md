## Golden Test Dataset — Translation Quality Validation

This directory contains human-approved translation samples used to validate
AI translation quality against expert human translations.

### Purpose

Compare:
1. **Source** — Original source text segment
2. **Human** — Expert human-approved translation
3. **AI** — AI-generated translation from the system

### Status Levels

- `implemented` — The language pair is in the language registry and the pipeline can generate output
- `tested` — The pipeline has been run against this file and generated output without errors
- `validated` — A human reviewer has compared AI output against approved translations

Do NOT label a language pair as `validated` without actual human review.
Do NOT invent "accuracy percentages".

### Directory Structure

```
golden/
  en-hi/
    sample-medical/
      source.xliff        — The input file
      human-approved.xliff — Human translation (add when available)
      ai-output.xliff     — Most recent AI output (generated by tests)
      review-notes.md     — Notes from human reviewer (add when reviewed)
  en-gu/
    ...
  en-ur/
    ...
```

### Instructions for Adding Approved Translations

1. Copy the source file into the appropriate language directory.
2. Create `human-approved.xliff` with human-translated target text.
3. Run the system against the source file.
4. Compare `ai-output.xliff` against `human-approved.xliff`.
5. Add reviewer notes to `review-notes.md`.
6. Update the language status in the language registry if appropriate.
